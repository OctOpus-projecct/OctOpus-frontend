# 클라이언트 작업 라우팅

작업에 필요한 문서만 선택한다. 이 표는 문서 읽기 안내이며 별도 에이전트 생성·모델 선택 설정이 아니다.

| 작업 | 읽을 문서 | 기준 요구사항 |
|---|---|---|
| 이슈 생성·수정·종료 | [이슈 규칙](tasks/issues.md) | 관련 제품 요구사항 |
| 브랜치·커밋·PR·병합 | [Git 절차](tasks/git-workflow.md) | 사용자 요청 범위·관련 이슈 |
| 코드 리뷰·리뷰 수정 | [리뷰 기준](tasks/review.md) | 대상 diff·검증 결과 |
| 기획·범위 변경 | [프로젝트 안내](project.md)의 기준 요구사항·개발 단계 | 해당 절의 확정·미정 상태 |
| 이동·카메라·입력·상호작용·자산 | [게임 표현](tasks/gameplay.md) | 3~4절 |
| 인벤토리·창고·상점·드랍·교환·퀘스트 UI | [화면과 아이템](tasks/ui.md) | 2, 5~7절 |
| 초기 설정·네트워크·공용 패키지 | [개발 절차](tasks/workflow.md), 백엔드 아키텍처 | 8절 |
| 버그·리팩터링·테스트·빌드 | [개발 절차](tasks/workflow.md) | 관련 기능 문서만 추가 |
| 서버 판정·저장·AWS | 백엔드 저장소의 `AGENTS.md`, `docs/agent-routing.md` | 클라이언트 수정 영향 확인 |

작업이 두 영역에 걸치면 두 경로를 함께 사용한다. 새 유형은 반복적으로 필요할 때 추가한다.
