# 이동·입력·벌목 표현

## 변경 전
- 기준 요구사항 3~4절을 확인한다. 현재 정해진 것은 클릭 이동, 재설정 가능한 조작, 기본 벌목 키 스페이스바다.
- 카메라 회전·확대, 이동 속도·상호작용 거리는 미정이다. 임시 시제품 값은 임시 값이라고 표시한다.

## 구현 기준
- 나무 선택 후 상호작용 거리까지 이동하고 서버가 작업 시작을 승인하면 벌목 상태를 표시한다.
- 타격 입력마다 행동을 요청한다. 서버가 허용한 결과와 애니메이션·이펙트를 일치시킨다.
- 남은 나무 체력, 스태미나, 제한시간, 다른 플레이어의 점유 상태를 알아볼 수 있게 표시한다. 표시 시간은 서버 상태를 기준으로 보정한다.
- 벌목 중 지면 클릭은 즉시 취소 의도와 이동을 전달한다. 서버의 독점 해제와 상태 초기화를 반영한다.
- 키 설정은 행동 이름을 기준으로 연결한다. 마우스 버튼 재설정과 UI 입력 차단을 함께 검증한다.
- 무게 초과 감속은 서버가 인정한 상태와 일치해야 한다.
- 서버에도 필요한 월드 충돌·배치 데이터는 백엔드와 공유 방식을 정한다. 클라이언트에만 존재하는 별도 게임 규칙을 만들지 않는다.

## 관련 변경 시 검증
- 클릭 목적지 이동, 장애물 처리, 도달 불가능한 나무, UI 클릭 시 이동 방지.
- 키 변경 후 이동·벌목, 벌목 중 지면 클릭 취소, 점유된 나무 접근.
- 클라이언트 2개에서 이동·벌목·재생성 일치, 지연 응답·접속 종료 후 표시 복구.
- 실제 엔진에서 카메라·애니메이션·자산 참조를 확인한다. 코드 검토만으로 시각 검증을 대신하지 않는다.
