# 인벤토리·상호작용 UI

## 변경 전
- 기준 요구사항 2, 5~7절을 읽는다. 세부 화면 배치는 아직 정해지지 않았다.
- 공용 아이템 식별자와 서버 상태를 기준으로 표시한다. 전체 아이템 종류와 개별 장비 표현은 도입 시 설계한다.

## 구현 기준
- 같은 종류 자원은 한 항목에 수량을 누적해 표시하고 현재 무게·최대 무게를 보여준다.
- 무게 여유 5% 이하의 채집 시작 금지와 최대 무게 초과 감속을 구분해서 안내한다.
- 바닥 줍기는 과적 상태에서도 무게를 이유로 비활성화하지 않는다. 채집 보상도 초과했다는 이유로 버리지 않는다.
- 개인 창고는 해당 플레이어의 내용만 보여준다. 용량 제한은 없으며 항목이 많아질 경우 표시·조회 범위를 나눈다.
- 아이템 버리기는 서버 성공 후 수량과 드랍 상태를 반영한다. 바닥 드랍 만료는 생성부터 3분이다.
- 교환은 제안 내용·양측 확인·서버 완료 상태를 구분한다. 내용 변경 시 확인 해제와 접속 종료 시 취소는 설계 제안이며 기능 도입 시 확정한다.
- NPC 전직은 수락·목재 납품·전직·도끼 지급 결과를 서버에서 받아 표시한다. 로컬에서 아이템을 먼저 확정 차감하지 않는다.
- 창고 출고·교환 수령의 무게 처리, 판매 가격, 계정 UI는 미정이다. 임의로 사용자 흐름을 확정하지 않는다.

## 관련 변경 시 검증
- 무게 경계·과적 줍기·보상 초과 후 표시, 수량 갱신, 초보자 도구 장착 제한.
- 창고 소유자 격리, 재접속 후 서버 데이터 표시, 실패·대기·빈 목록 상태.
- 중복 클릭·지연 응답에서도 판매·교환·납품 완료를 중복 표시하지 않는지 확인한다.
