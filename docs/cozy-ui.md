# 생활 RPG UI 개편

사용자 승인 범위: 크림색·연두색·나무색의 둥근 UI. 로그인 카드, 게임 하단 도끼/스태미나, 선택한 나무 체력/시간, 가방 창, 설정과 개발 정보 토글을 제공한다. 맵 자산과 서버 게임 규칙은 바꾸지 않는다.

## 구현과 검증 순서
1. 기존 계정 화면에 의존하는 UI 작업 브랜치를 최신 dev에서 시작하고 계정 PR 변경을 포함한다. 계정 PR이 선행되어야 하며 dev 병합은 사용자 결정이다.
2. CozyHud에 화면 표현을 분리한다. 서버에서 복원된 인벤토리·나무·스태미나만 표시한다. UI 좌표와 클릭 차단은 같은 비율로 확대/축소한다.
3. 설정에서 이동 마우스 버튼과 벌목 키를 계속 변경할 수 있게 한다. 개발 정보는 기본적으로 숨긴다.
4. Unity 빌드·PlayMode·실제 렌더 캡처와 UI 클릭 차단, 기존 벌목/인벤토리 회귀를 확인한다. 별도 리뷰 후 dev 대상 초안 PR을 만든다.

## 직접 확인
게임을 재실행하면 로그인 카드가 나온다. 만든 계정으로 접속하면 상단 가방/설정과 하단 스태미나가 보인다. 나무를 선택하면 체력·작업 시간이 표시된다. 가방에서 목재 수량과 무게를 확인한다. 가방·설정·HUD 클릭 시 캐릭터가 이동하지 않아야 한다. 설정에서 조작을 변경한 뒤 실제 벌목을 확인한다.

로그인은 서버 주소와 계정 정보, 접을 수 있는 서버 인증 설정을 제공한다. 인증서 지문을 이미 파일로 준비한 사용자는 다시 입력하지 않아도 된다. 인벤토리는 서버 확정 값을 표시하며 과적 상태와 95% 채집 제한을 구분한다.

## 렌더 검증
OCTOPUS_UI_CAPTURE에 제외된 출력 폴더를 지정한 개발용 실행에서만 CozyPreview가 동작한다. 실제 로그인 화면→접속→HUD→가방/나무→설정 PNG와 입력 차단 검사 결과를 남긴다. 기본 실행에는 자동 접속·자동 이동·캡처를 적용하지 않는다.

## 현재 검증 상태
Windows 클라이언트 빌드, PlayMode 22개, 문서 검사가 통과했다. 별도 리뷰의 키 변경 대기 해제·동적 자원 정리·검증 서버 바인딩 지적을 반영했다. 숨겨진 창에서는 캡처가 검거나 실패하여 시각 검증을 완료하지 않았다. 화면을 보이는 테스트는 명시적 -ShowWindow 옵션으로 실행한다. 사용자 수동 플레이와 시각 검증은 대기 상태이며 초안 PR로 유지한다.
