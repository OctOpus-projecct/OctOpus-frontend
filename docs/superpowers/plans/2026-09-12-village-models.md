# 시작 마을 3D 모델 적용 계획

사용자 승인 시안: `docs/art/starting-village-approved.png`. 02 주민은 도끼를 들지 않는다. 시작 지역은 작은 마을이며 마법학교는 후반 대도시 설정이다.

목표: 시안의 색·비율·실루엣을 실제 Unity 3D 메시와 프리팹으로 적용한다. 생성 이미지와 픽셀 단위 일치를 주장하지 않으며 실제 렌더를 별도로 제공한다.

구현 스킬: subagent-driven-development. 독립 모델군을 나누어 제작하고, 합친 뒤 별도 리뷰와 실제 엔진 검증을 수행한다.

- [x] 원본 시안 보관, 에디터용 메시/머티리얼 생성 도구와 프리팹 생성 명령 추가.
- [x] 캐릭터·도끼·가방·도끼 없는 주민: 앞면 얼굴, 머리카락, 의상, 팔다리 계층을 가진 모델. 서버 위치 변화와 승인 타격 시퀀스로 걷기·벌목 동작.
- [x] 나무·그루터기·목재·집·공방·마법 가로등·이정표·초목 메시. 나무 고갈/재생은 서버 상태로 표현. 건물은 플레이 경계 밖에 두어 이동을 방해하지 않음.
- [x] 기존 Collider·NetworkObject·나무 5개 위치·캐릭터 이동 높이와 RPC 유지. 기본 도형 Renderer만 대체하며 독점/인벤토리 색 덮어쓰기 제거.
- [x] 렌더 텍스처 기반 모델 미리보기 및 PlayMode/네트워크 회귀. 실제 게임창을 새로 띄우지 않고 모델 메시를 별도 카메라로 렌더.
- [x] 문서·별도 리뷰·dev 초안 PR. 선행 계정/UI PR 의존성 명시, 자동 병합 금지.

주요 파일: Editor/VillageArt/ (모델 생성), Resources/Village/ (구운 메시/프리팹), OctOpus/CharacterModelView.cs, TreeModelView.cs, PrototypeMapView.cs, ClientBootstrap.cs. 공유 패키지 및 서버 규칙은 변경하지 않는다.
