# 양손 도끼 파지와 벌목 모션 구현 계획

목표: 손목을 관통하거나 팔 전체가 막대처럼 회전하는 인상을 줄이고, 양손 파지·준비·당기기·타격·복귀를 실제 모델로 구현한다.

구조: 클라이언트 표현 전용 `WoodcuttingPose`가 손잡이 기준 손 위치와 두 관절 팔 자세를 계산한다. 런타임과 렌더 미리보기가 같은 함수를 사용한다. 서버가 승인한 `StrikeSequence`만 타격을 시작한다.

기술: Unity 6.3, C#, 절차적 메시, 두 관절 IK, PlayMode 테스트.

기준: 사용자 요청, `docs/tasks/gameplay.md`. Palia 공식 벌목 이미지의 양손 파지와 몸통 회전을 참고하되 외부 모델·애니메이션 자산은 사용하지 않는다.

제약: 기존 머리·모자 보존, 서버 규칙·입력·쿨다운 변경 없음, 기존 PR #25의 dev 대상 유지. 원본 저장소 사용자 변경 보존.
